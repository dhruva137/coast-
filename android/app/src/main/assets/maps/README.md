# Bundled offline basemap (P0-4)

`demo_neighbourhood.mbtiles` — small **raster** pack (Carto `dark_all` / OSM data)
covering the real IO-VNBD drive **S-S1** (Coventry, UK) used by the blackout
replay, so the replayed dot sits on the actual streets it was driven on.

| | |
|---|---|
| Bbox | ~52.398–52.4115 N, -1.601–-1.587 E (IO-VNBD S-S1 strip) |
| Zooms | 13–18 |
| NOT included | Full India/UK, full city, vector tiles |

Generated by `tools/build_demo_mbtiles.py`. Re-run that script if you need a
different bbox. Airplane-mode demos outside this bbox will show empty tiles
(dark background) until live/cached tiles are available.
